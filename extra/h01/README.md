# Практична 1

## Відкрита дискусія

**Чим програма відрізняється від алгоритму?**

Алгоритм — це чітка послідовність кроків для розв'язання задачі. Програма — це алгоритм, записаний мовою програмування так, щоб його міг виконати комп'ютер.

**Навіщо потрібні мови програмування, якщо процесор їх усе одно не розуміє?**

Мови програмування дають змогу людині записувати інструкції у зрозумілій формі. Компілятор або інтерпретатор перетворює їх на машинні інструкції, які може виконувати процесор.

**Чи може комп'ютер зробити щось, чого йому не казали?**

Комп'ютер виконує задані інструкції, але результат може бути неочікуваним через помилки в програмі, неправильні дані або не враховані умови.

**Чи є рецепт борщу алгоритмом?**

Так. Рецепт містить послідовність дій та умови їх виконання, тому його можна розглядати як алгоритм.

**Опишіть, як зав'язати шнурки, для того, хто ніколи їх не бачив.**

Перехрестити два кінці шнурка, провести один кінець під іншим і затягнути. Зробити петлю з одного кінця, обвести її другим кінцем, протягнути його крізь отвір і затягнути обидві петлі.

**Програма правильно порахувала всі приклади з дошки. Чи це доводить, що вона працює?**

Ні. Приклади з дошки перевіряють лише окремі випадки. Потрібно також перевірити граничні та нетипові вхідні дані.
