# Практична 6. Відкрита дискусія
## Символи, кодування та рядки

### 1. Як комп'ютер зберігає літеру, якщо вміє зберігати тільки числа?

Комп'ютер зберігає інформацію у вигляді бітів — нулів і одиниць. Кожному символу відповідає певний числовий код. Наприклад, у таблиці ASCII літера `A` має код 65. Під час збереження тексту цей код перетворюється на двійкове число. Для правильного відображення тексту програма повинна знати, яке кодування використано.

### 2. Чому 'A' і "A" — це різні речі?

У Java `'A'` — це символьний літерал типу `char`, який представляє один символ. `"A"` — це рядковий літерал типу `String`, який містить текст із одного символу. Вони відрізняються типом даних і способом використання в програмі. Наприклад, `char` можна порівнювати як окремий символ, а `String` має методи для роботи з текстом.

### 3. Чим порожній рядок відрізняється від відсутнього?

Порожній рядок `""` — це рядок, який існує, але не містить жодного символу. Відсутність рядка в Java зазвичай позначається значенням `null`. Порожній рядок можна використовувати для обробки тексту, а звернення до методів через `null` може спричинити помилку `NullPointerException`.

### 4. Звідки беруться «кракозябри» замість тексту?

«Кракозябри» виникають, коли текст записано в одному кодуванні, а програма читає його в іншому. Наприклад, байти UTF-8 можуть бути неправильно інтерпретовані як Windows-1251. Через це замість правильних літер з'являються незрозумілі символи. Щоб уникнути проблеми, потрібно правильно вказувати кодування під час читання та запису файлів.

### 5. Скільки літер у смайлику 👨‍👩‍👧?

Візуально це один емодзі, який зображає сім'ю. Проте технічно він складається з кількох кодових точок Unicode, об'єднаних спеціальними символами. У Java довжина такого рядка в `char` може бути більшою за кількість символів, які людина сприймає як окремі графічні елементи. Тому довжина рядка не завжди дорівнює кількості видимих символів.

### 6. Чому слово «Привіт» у файлі важить більше, ніж «Hello»?

У кодуванні UTF-8 латинські літери слова `Hello` займають по одному байту, тобто загалом 5 байтів. Кириличні літери слова `Привіт` у UTF-8 зазвичай займають по два байти кожна, тому слово потребує 12 байтів. Це пов'язано з тим, що символи мають різні числові коди Unicode та різну довжину представлення в UTF-8.
