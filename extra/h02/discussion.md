# Практична 2 — відкрита дискусія

## 4. Відкрита дискусія

### 1. Чому комп'ютер рахує двійками, а не десятками, як ми?

Комп'ютер працює з електронними схемами, які найпростіше мають два стабільні стани: увімкнено і вимкнено. Тому для представлення даних зручно використовувати двійкову систему числення з цифрами 0 і 1.

### 2. Що таке біт і чому саме вісім бітів назвали байтом?

Біт — найменша одиниця інформації, яка може мати значення 0 або 1. Байтом традиційно називають 8 бітів. Вісім бітів дають (2^8 = 256) можливих комбінацій, тому одного байта достатньо для представлення 256 різних значень.

### 3. Як записати від'ємне число, якщо в пам'яті є лише нулі й одиниці?

Від'ємні числа кодують за спеціальними правилами. Найпоширеніший спосіб для цілих чисел — додатковий код (two's complement). Наприклад, у 8-бітному представленні число -1 записується як 11111111.

### 4. Чому виникає переповнення і як з ним боротися?

Переповнення виникає, коли результат обчислення виходить за межі діапазону, який може зберігати вибраний тип даних. Боротися з ним можна вибором типу з більшим діапазоном, перевіркою меж перед операцією та використанням відповідних алгоритмів і типів даних.

### 5. Чому в старих іграх максимум золота — рівно 2 147 483 647?

Число 2 147 483 647 — це максимальне значення знакового 32-бітного цілого числа: (2^{31}-1). Якщо кількість золота зберігалася в такому типі, перевищити це значення без зміни способу зберігання було неможливо.

### 6. Чому комп'ютер вважає, що 7 / 2 = 3?

Якщо обидва числа є цілими, використовується цілочисельне ділення. Дробова частина відкидається, тому 7 / 2 дає 3, а не 3,5. Для отримання 3,5 потрібно використовувати числа з дробовою частиною, наприклад 7.0 / 2.0.
