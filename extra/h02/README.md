# Практична 2

## Відкрита дискусія

**Чому комп'ютер рахує двійками, а не десятками, як ми?**

Транзистори в процесорі мають два основні стани, які зручно представляти як 0 і 1. Тому комп'ютери використовують двійкову систему числення.

**Що таке біт і чому саме вісім бітів назвали байтом?**

Біт — це 0 або 1. Вісім бітів утворюють байт і дають 256 можливих комбінацій.

**Як записати від'ємне число, якщо в пам'яті є лише нулі й одиниці?**

Для від'ємних цілих чисел використовують додатковий код (two's complement).

**Чому виникає переповнення і як з ним боротися?**

Переповнення виникає, коли результат не поміщається в діапазон типу даних. Можна використати тип із більшим діапазоном або перевіряти межі перед операціями.

**Чому в старих іграх максимум золота — рівно 2 147 483 647?**

Це максимальне значення знакового 32-бітного типу int: 2^31 - 1.

**Чому комп'ютер вважає, що 7 / 2 = 3?**

При цілочисельному діленні дробова частина відкидається. Для отримання 3,5 потрібно використати дробовий тип, наприклад 7.0 / 2.
