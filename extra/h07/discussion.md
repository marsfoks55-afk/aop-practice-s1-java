# Відкрита дискусія

## 1. Як комп'ютер зберігає літеру, якщо вміє зберігати тільки числа?
Комп'ютер зберігає текст як числа — байти. Кодування, наприклад UTF-8, визначає, яким числовим послідовностям відповідають символи.

## 2. Чому 'A' і "A" — це різні речі?
У багатьох мовах програмування одинарні лапки позначають символ, а подвійні — рядок. Наприклад, у Java `char c = 'A';`, а `String s = "A";`. `char` у Java — це одна 16-бітна кодова одиниця UTF-16, а `String` — послідовність таких одиниць.

## 3. Чим порожній рядок відрізняється від відсутнього?
Порожній рядок `""` існує, але має довжину нуль. Відсутнє значення, наприклад `null` у Java, означає, що об'єкт рядка не заданий. Це різні стани.

## 4. Звідки беруться «кракозябри» замість тексту?
Зазвичай через невідповідність кодування під час запису й читання. Наприклад, байти UTF-8 інтерпретують як Windows-1251 або навпаки, тому відображаються неправильні символи.

## 5. Скільки літер у смайлику 👨‍👩‍👧?
Це один видимий емодзі, складений із трьох емодзі людей та двох з'єднувачів нульової ширини ZWJ. У рядку п'ять кодових точок Unicode: три емодзі людей і два з'єднувачі. У Java UTF-16 це вісім кодових одиниць. Отже, відповідь залежить від того, що рахувати: видимі графеми, кодові точки чи кодові одиниці.

## 6. Чому слово «Привіт» у файлі важить більше, ніж «Hello»?
У UTF-8 латинські літери в `Hello` займають по одному байту, а кириличні літери в `Привіт` — по два байти. Тому `Hello` займає 5 байтів, а `Привіт` — 12 байтів у UTF-8.
