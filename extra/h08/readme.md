Відкрита дискусія

1. Як знайти найбільше число в масиві?

Потрібно пройти циклом по всіх елементах масиву та порівнювати їх. Спочатку найбільшим вважається перший елемент, а якщо знаходиться більше число, значення оновлюється.

2. Чому майже кожна задача на масив починається з одного проходу циклом?

Один прохід дозволяє перевірити кожен елемент масиву та знайти потрібний результат. Це ефективний підхід, оскільки складність алгоритму зазвичай становить O(n).

3. Що має робити код, якщо масив порожній?

Потрібно перевірити, чи масив містить елементи, перш ніж звертатися до них. Якщо масив порожній, програма має коректно обробити цю ситуацію, наприклад повернути спеціальне значення або повідомити про помилку.

4. Як за один прохід знайти найкращий день купити й найкращий продати акції?

Потрібно зберігати мінімальну ціну, яку зустріли раніше, та найбільший можливий прибуток. Для кожного наступного дня обчислюється різниця між поточною ціною та мінімальною попередньою.

5. Тисяча запитів «яка сума чисел з 10-го по 1000-й?» — як відповідати миттєво?

Якщо діапазон не змінюється, суму можна обчислити один раз і зберегти результат. Для послідовних цілих чисел використовується формула суми арифметичної прогресії. Сума чисел від 10 до 1000 включно дорівнює 500455.

6. Чи корисно вчити готові прийоми, чи вони заважають думати самому?

Готові прийоми допомагають швидше розв'язувати типові задачі та знаходити ефективні рішення. Проте важливо розуміти принцип їхньої роботи, а не просто копіювати код. Найкраще спочатку спробувати розв'язати задачу самостійно, а потім порівняти свій підхід із готовим рішенням.
