# Практична 3

## Відкрита дискусія

**Навіщо потрібні окремі типи для цілих і дробових чисел?**

Цілі та дробові числа мають різне внутрішнє представлення і різні правила обчислень. Окремі типи дозволяють ефективно зберігати значення та визначати потрібну точність.

**Що означає «рухома кома» і куди вона рухається?**

У floating-point числах положення двійкової коми не фіксоване. Воно визначається показником степеня і залежить від величини числа.

**Скільки цифр після коми комп'ютер здатен запам'ятати?**

Це залежить від типу даних. Для Java double точність становить приблизно 15–17 значущих десяткових цифр.

**Чому 0.1 + 0.2 не дорівнює 0.3?**

Багато десяткових дробів не можуть бути представлені точно у двійковому форматі floating-point, тому виникає невелика похибка.

**Чому гроші ніколи не зберігають у double?**

Через похибки floating-point фінансові обчислення можуть давати неточні результати. Для грошей використовують цілі найменші одиниці або BigDecimal.

**Чи може число не дорівнювати саме собі?**

Так. Значення NaN у floating-point не дорівнює навіть самому собі: NaN != NaN.
