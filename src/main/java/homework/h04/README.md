# Практична 4

## Відкрита дискусія

**Навіщо в програмуванні окремий тип для «так» і «ні»?**

Тип `boolean` зберігає два значення: `true` і `false`. Він потрібен для перевірки умов, виконання логічних операцій і прийняття рішень у програмі.

**Як сказати `!(a && b)` людською мовою?**

Це означає, що обидві умови не можуть бути одночасно істинними. Тобто хоча б одна з умов `a` або `b` має бути хибною.

**Чим `&&` відрізняється від `&`?**

Оператор `&&` використовує коротке замикання: якщо перша умова хибна, друга не перевіряється. Оператор `&` перевіряє обидва логічні операнди, а для цілих чисел виконує побітову операцію І.

**Чому програма не падає в `if (x != null && x.name == "Іван")`, хоча `x` порожній?**

Якщо `x == null`, перша умова `x != null` є хибною. Через коротке замикання оператор `&&` не виконує другу умову, тому звернення до `x.name` не відбувається.

**Як запхати 32 відповіді «так/ні» в одне число?**

Можна використати 32 біти типу `int`. Кожен біт зберігає одну відповідь: `1` означає «так», а `0` — «ні». За допомогою побітових операторів можна перевіряти та змінювати окремі відповіді.

**Що швидше: `n % 2` чи `n & 1`?**

`n % 2` обчислює остачу від ділення на два, а `n & 1` перевіряє молодший біт числа. Побітова операція зручна для перевірки парності, але сучасний компілятор може оптимізувати обидва варіанти, тому без вимірювань не можна стверджувати, що один завжди швидший.
