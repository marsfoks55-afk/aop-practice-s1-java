4. Відкрита дискусія

1. Навіщо в програмуванні окремий тип для «так» і «ні»?

Для цього існує тип boolean, який має два значення: true (так) і false (ні). Він використовується для перевірки умов, виконання логічних операцій і прийняття рішень у програмі.

2. Як сказати !(a && b) людською мовою?

Цей вираз означає: «Неправда, що обидві умови одночасно істинні». Тобто хоча б одна з умов a або b має бути хибною.

3. Чим && відрізняється від &?

Оператор && виконує логічне І з коротким замиканням: якщо перша умова хибна, друга вже не перевіряється. Оператор & для логічних значень перевіряє обидва операнди, а для цілих чисел виконує побітову операцію І.

4. Чому програма не падає в if (x != null && x.name == "Іван"), хоча x порожній?

Це відбувається завдяки короткому замиканню оператора &&. Якщо x == null, умова x != null є хибною, тому звернення до x.name не виконується. Таким чином, помилка доступу до властивості null не виникає.

5. Як запхати 32 відповіді «так/ні» в одне число?

Можна використати всі 32 біти типу int. Кожен біт зберігає одну відповідь: 1 означає «так», а 0 — «ні». За допомогою побітових операторів і масок можна перевіряти, встановлювати та змінювати окремі біти.

6. Що швидше: n % 2 чи n & 1?

Вираз n % 2 знаходить остачу від ділення на два, а n & 1 перевіряє молодший біт числа. Обидва способи використовують для перевірки парності. Побітова операція може бути ефективною, але сучасний компілятор здатний оптимізувати обидва варіанти, тому без вимірювань не можна стверджувати, що один завжди швидший.
